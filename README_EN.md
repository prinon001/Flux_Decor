## About
Customize status bar clock, network speed, signal indicators, notification panel / control center, combined triple icons, lock screen widgets and more. Break free from rigid native styles. Changes take effect instantly with lightweight runtime.

## Features
LSPosed Scope: `com.android.systemui` (System UI)<br>Below is a partial list of features. Explore more after installation.
| Element | Partial Features |
|---|---|
Status Bar Clock | Custom format, free position adjustment, background support, emoji, text, power consumption, temperature, etc.
Status Bar Notifications | Double-row layout, free positioning, size & count adjustment
Status Bar Network Speed | Double-row layout, adjustable position, font size, symbol, refresh interval
Status Bar Power Consumption | Double-row layout, adjustable position, font size, symbol, refresh interval
Status Bar Signal | Dual-row display, separate 5G display, signal bar editing, custom icon import, adjustable 5G icon size
Status Bar Wi‑Fi | Custom corner badges, Wi‑Fi bar editing, custom icon import
Status Bar Battery | Numeric / percentage display, multiple styles, adjustable size & position
Status Bar Combined Icons | Triple combined icon display, adjustable size, position and color
Status Bar Info Strip | Free positioning, supports weather / static text / device info display
Status Bar Graphics | Import custom graphics, built-in presets, free positioning, scheduled switching
Status Bar Status Icons | Move Bluetooth / mute icons to the left, custom icon import, built-in presets, adjustable size and position
Status Bar Connected Device Icons | Show headset / speaker icons on the left, custom icon import, built-in presets, adjustable size and position
Lock Screen | Hide fingerprint ring, notification sinking, depth of field unlock, widgets, bottom bar music, keyboard background, built-in graphics
Home Screen Widgets | Multi-size widgets, dozens of customizable content items
Notification Center | iOS-style layout, free positioning, built-in numeric styles, second display, focus notification background
Control Center | iOS-style layout, top-left edit button / top-right power button, custom icon import, built-in graphics
Soft Glass Tuning | Adjust glass blur parameters for notification & control panels
Other Tweaks | Customize / hide green dot indicator and navigation bar indicator
