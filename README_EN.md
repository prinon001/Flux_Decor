## Project Introduction
Customize status bar time, network speed, signal indicators, notification panel / control center, triple-in-one icons, lock screen widgets and more. Break free from fixed native styles. Changes take effect instantly with lightweight runtime.

## Features
Partial features are shown below. Explore more after installation.
## Status Bar Time
Custom format, adjustable position, support for background, emojis, text, power consumption, temperature, etc.
## Status Bar Notifications
Double-row layout, freely adjustable position, customizable size and quantity.
## Status Bar Network Speed
Double-row layout, adjustable position, font size, symbols, refresh interval, etc.
## Status Bar Power Info
Double-row layout, adjustable position, font size, symbols, refresh interval, etc.
## Status Bar Signal
Double-row display, separate 5G indicator, signal bar editing, custom icon import, adjustable 5G icon size, etc.
## Wi-Fi
Custom left/right corner badges, Wi-Fi bar editing, support for custom icon import.
## Battery
Percentage display, multiple styles, adjustable size and position.
## Combination
Triple-in-one combined icon display with adjustable size, position and color.
## Status Bar Info Strip
Freely adjustable position, supports weather / custom text / device information display.
## Status Bar Patterns
Import custom patterns, multiple built-in patterns, adjustable position, scheduled switching.
## Status Bar Status Icons
Show Bluetooth / mute and other icons on the left side, custom icon import, built-in icons, adjustable position.
## Status Bar Connected Device Icons
Show headphones / speaker and other connected devices on the left side, custom icon import, built-in icons, adjustable position.
## Lock Screen
Hide fingerprint ring / sink notifications / remove depth of field effect / widgets / bottom bar music, keyboard background customization, multiple built-in patterns.
## Desktop Widgets
Widgets in various sizes with dozens of customizable content options.
## Notification Center
iOS-style layout support, freely adjustable position, built-in digit styles, seconds display / focus notification background.
## Control Center
iOS-style layout support, top-left edit button / top-right power button, custom icon import, built-in patterns available.
## Frosted Glass Tuning
Adjust glass blur parameters for notification panel and control center.
## Other Tweaks
Customize or hide the green dot indicator and gesture bar color.
